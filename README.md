
# 📄 AI PDF Chatbot

Apne PDF se baat karo! PDF upload karo aur usse koi bhi sawal pucho.

**🚀 Live Demo:** https://q4xxgtevcbisdqongg2enj.streamlit.app/


## Features
- 📤 PDF Upload karo
- 🤖 AI se sawal pucho
- 💬 Chat jaisa interface
- ⚡ Fast aur Easy

## Tech Used
- Python
- Streamlit
- Groq AI
- PyPDF2

## Kaise Chalaye?
1. Repo ko clone karo
2. `pip install -r requirements.txt` chalao
3. `.env` file me apni `GOOGLE_API_KEY` daalo
4. `streamlit run app.py` chalao
