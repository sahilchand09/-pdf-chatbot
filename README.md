# 📄 PDF Chatbot

Apne PDF se baat karo! Koi bhi PDF upload karo aur usse sawal pucho.

## Features
- 📤 PDF Upload karo
- 🤖 AI se sawal pucho
- 💬 Chat jaisa interface
- ⚡ Fast aur Easy

## Tech Used
- Python
- Streamlit
- Google Gemini AI
- PyPDF2

## Kaise Chalaye?
1. Repo ko clone karo
2. `pip install -r requirements.txt` chalao
3. `.env` file me apni `GOOGLE_API_KEY` daalo
4. `streamlit run app.py` chalao
